## 電玩產業鏈四層

1. **上游硬體層** — 晶片、主機、周邊、顯示器
2. **中游內容層** — 研發、發行、數位平台、行動遊戲
3. **下游通路層** — 電競館、專賣店、主題樂園、二手平台
4. **生態支援層** — 賽事、實況、支付、法規

## 325 遊樂場

81 款分類小遊戲（10 大分類），包含：
- 街機類：太空射擊、打磚塊、貪吃蛇、無盡跑酷
- 益智類：2048、數獨、滑動拼圖、迷宮
- 棋類：五子棋、井字棋、黑白棋
- 反應類：打地鼠、反應測試、接金幣
- 桌遊類：21 點、骰子、幸運輪盤

## 技術棧

- 純 HTML5 + CSS3 + Vanilla JavaScript
- 無框架、無建置工具
- 響應式設計（Desktop / Tablet / Mobile）
- 深黑藍底色系（#0a0e15），遊戲分類區採淺色卡片
- Noto Sans TC + Inter 字體（CDN）
- 部分頁面使用 three.js（CDN）
