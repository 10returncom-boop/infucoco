# INFUCOCO — 程式架構文件（Code Architecture）

---

## 1. 目錄結構

```
infucoco.com/
├─ index.html / quotes.html / stories.html / games.html / play.html
├─ quiz.html / gallery.html / stickers.html / shop.html / member.html
├─ about.html / sitemap.html
├─ fable-cosmic-cafe.html / fable-fireworks.html / fable-star-seed.html
├─ sitemap.xml
├─ assets/
│  ├─ favicon.png
│  ├─ webp/   ← game_g01.webp…game_g100.webp（100 張遊戲縮圖）
│  └─ media/  ← 舊 IP 場景圖
├─ css/main.css
├─ js/
│  ├─ config.js      → window.CFG（站名/分類/i18n）
│  ├─ quotes.js      → 金句資料
│  ├─ service.js     → window.Svc（主題切換等）
│  ├─ utils.js       → 粒子/麵包屑/工具列/搜尋/捷徑
│  ├─ stories.js     → 寓言資料
│  └─ games/
│     ├─ games-data.js → window.GAMES / GAME_MAP（100 款）
│     └─ games.js      → window.GameEngines（10 引擎）
└─ docs/
   ├─ 規格書.md
   ├─ 變數清單.md
   └─ 程式架構.md（本檔）
```

> JS 檔名含 `@v=20261003v6` 後綴（當作 cache-busting 版本字串，實體檔名一部分）。

## 2. 請求到畫面的流程

```
使用者點 games.html 卡片
  → href = play.html?g=g03
  → play.html 用 URLSearchParams 讀 g=g03
  → GAMES.find(id=g03) 取該筆資料
  → GameEngines[ game.ty ](game).start(stage, onScore, onEnd)
  → 渲染玩法；onEnd 時寫 localStorage["infu_best_g03"]
```

## 3. 遊戲引擎架構（`games.js`）

```
window.GameEngines = (function(){
  function makeTimer()      // 每局一個：loop/later/stop/clear，防 replay 殘留
  function themeSet(game)   // 以 game.i（該遊戲 emoji）組主題符號
  function endHTML(score,game,msg)  // 共用結束畫面 + 再玩一次
  return { catch, whack, memory, quiz, timing,
           reaction, count, order, match, sequence }
})();
```

### 3.1 一致契約
- 每個引擎回傳 `{ start(stage, onScore, onEnd) }`
- `onScore / onEnd` 預設為空函式（避免未傳時 TypeError）
- 進入新一局先 `timer.clear()`，確保舊計時器全數清除
- 結束呼叫 `onEnd(score)` 後才 render 結束畫面

### 3.2 新增一種玩法
1. 在 `GameEngines` 內寫 `function xxxGame(g){ return {start(stage,onScore,onEnd){…}} }`
2. 註冊進 return 物件：`xxx:xxxGame`
3. 把想做此玩法的遊戲資料 `ty:"xxx"` 即可（無需動 HTML）

---

## 4. 資料流重點

- **單一資料源**：所有卡片、計分、連結都由 `GAMES` 驅動；新增遊戲只需在 `games-data.js` 加一筆。
- **圖片對應**：卡片 `background-image: assets/webp/game_${g.id}.webp`，檔名與 id 一致。
- **最佳分**：僅存瀏覽器 localStorage，跨裝置不同步（無後端）。
