## 1. 系統概述

INFUCOCO 是一個純 HTML / CSS / JS 的靜態網站，核心互動為「100 款療癒小遊戲」。
玩家從 `games.html` 卡片牆選遊戲，進入 `play.html?g=<gameId>` 後由共用遊戲引擎渲染單一玩法，最佳分數存於 localStorage。

- 技術棧：純 HTML / CSS / JS（無框架、無建置步驟）
- 編碼：UTF-8　語言：繁體中文（zh-Hant）
- 圖片：WebP，位於 `assets/webp/`
- 部署：靜態主機（Cloudflare Pages / GitHub Pages），無後端

## 3. 遊戲資料結構

每款遊戲為 `window.GAMES` 陣列中一筆物件：

```js
{ id:"g01", lv:2, t:"接住彩虹氣球", c:"react", ty:"catch",
  i:"🎈", d:"接住所有落下的療癒小物，別讓它們掉落。", p:2 }
```

| 欄位 | 意義 | 範例 |
|---|---|---|
| `id` | 遊戲編號（g01–g100） | `g01` |
| `lv` | 難度 1–3 | `2` |
| `t` | 遊戲名稱 | `接住彩虹氣球` |
| `c` | 分類（6 選 1） | `react` |
| `ty` | 玩法引擎（10 選 1） | `catch` |
| `i` | 代表 emoji（同時作為卡片與遊戲主題符號） | `🎈` |
| `d` | 一句話描述 | `接住所有落下的療癒小物…` |

另提供 `window.GAME_MAP[id]` 快速查表。

### 3.1 分類（6）
| c | 名稱 | 數量 |
|---|---|---|
| react | 反應 | 17（g01–g17）|
| puzzle | 益智 | 17（g18–g34）|
| fable | 寓言 | 17（g35–g51）|
| pet | 療癒/寵物 | 16（g52–g67）|
| arcade | 玩樂 | 16（g68–g83）|
| creative | 創作 | 17（g84–g100）|

## 4. 遊戲引擎（10 種玩法）

所有引擎由 `js/games/games.js` 的 `window.GameEngines` 提供，統一介面：

```js
const engine = GameEngines[ty](game);   // game 為該筆 GAMES 資料
engine.start(stageEl, onScore, onEnd);
// onScore(score)：即時分數更新（可選）
// onEnd(score)：一局結束，供 play.html 寫入最佳分
```

| ty | 玩法 | 規則重點 | 時長 |
|---|---|---|---|
| catch | 接物 | 點擊落下的主題 emoji 得分，30 秒倒數 | 30s |
| whack | 打地鼠 | 9 宮格隨機冒出主題 emoji，點擊得分 | ~20s |
| memory | 記憶配對 | 翻牌配對，6 對全數配對完畢 | 不限時 |
| quiz | 問答 | 12 題庫隨機抽 6 題 | 6 題 |
| timing | 時機 | 游標在中央白線時按下，12 次機會 | 12 次 |
| reaction | 反應 | 畫面隨機出現主題 emoji 即點即消 | ~20s |
| count | 數數 | 數畫面 emoji 數量，二選一，8 題 | 8 題 |
| order | 排序 | 依邏輯先後（種子→開花→盛開等）點選 | 3 步 |
| match | 連連看 | 左表情 ↔ 右標題配對，4 組 | 不限時 |
| sequence | 記憶順序 | Simon-says 式跟隨閃光順序，逐關加長 | 6 關 |
