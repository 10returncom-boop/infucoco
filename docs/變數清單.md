## 3. 遊戲可調參數（在 `games.js`）

| 引擎 | 變數 | 目前值 | 說明 |
|---|---|---|---|
| catch | `left` 倒數 / spawn 間隔 | 30s / 620ms | 時長、出物頻率 |
| whack | `ticks` 上限 / 冒出間隔 | 40 次 / 500ms | 時長、難度 |
| memory | `pairs` | 6 | 牌組對數 |
| quiz | 題庫抽題數 | 6（庫存 12）| 局內題數 |
| timing | `tries` | 12 | 機會數 |
| reaction | `ticks` 上限 / 間隔 | 33 / 600ms | 時長、難度 |
| count | 題數 / emoji 數範圍 | 8 / n=2–7 | 局長、難度 |
| order | PATHS | 3 組邏輯序列 | 可自訂更多先後 |
| match | items | 4 組 | 配對數量 |
| sequence | 起始長度 / 上限 | round+1 / 6 | 記憶長度 |
